## 1. Концепция и позиционирование

### Одна фраза
> Каталог услуг бьюти-мастера с онлайн-записью — всё внутри Telegram, без звонков и сайтов.

### Для кого
- **Клиент:** открывает из Telegram, видит услуги с фото и ценами, выбирает время, записывается за 3 тапа
- **Мастер:** получает записи автоматически, без ручного управления в переписке

### Ключевые принципы продукта
1. **Мастер — личность, не прайс-лист.** Продаём человека, а не список услуг
2. **Максимум визуала, минимум текста.** Бьюти — эмоция, а не таблица
3. **3 тапа от открытия до записи.** Чем меньше шагов, тем выше конверсия
4. **Нативный Telegram.** Выглядит как часть мессенджера, не как сторонний сайт

## 2. Навигация и структура

### Bottom navigation bar — 4 таба

```
[  Главная  ]  [  Услуги  ]  [  Записи  ]  [  Мастер  ]
     🏠              💅            📅             👤
```

- Всегда видна, кроме экранов booking flow (там — только BackButton + MainButton)
- Активный таб — акцентный цвет `--tg-theme-button-color`
- Иконки — линейные, одноцветные, 24px

### BackButton (шапка Telegram)
- Показывается на всех экранах, кроме четырёх корневых табов
- Управляется через `Telegram.WebApp.BackButton`
- На корневых экранах — скрыт

### MainButton (нижняя кнопка Telegram)
- Используется для всех primary CTA внутри booking flow
- Меняет текст в зависимости от экрана: "Выбрать время", "Подтвердить запись", "Оплатить"
- Скрыта на экранах Главная, Услуги, Записи, Мастер (там своя навигация)

## 3. Экраны — подробное описание

---

### Экран 1: Главная

**Назначение:** первое впечатление, возврат к последней записи, быстрый переход в каталог

#### Элементы сверху вниз

**Блок 1 — Hero мастера**
- Фото мастера: полная ширина, соотношение 4:3, скруглённые углы снизу
- Поверх фото (gradient overlay снизу):
  - Имя мастера — 22px bold, белый
  - Специализация — 14px, белый 80% opacity ("Маникюр · Педикюр · Наращивание")
- Высота блока: 220px

**Блок 2 — Персонализированное приветствие** *(только при наличии истории)*
- Карточка с серым фоном `--tg-theme-secondary-bg-color`
- Текст: "Привет, [имя из Telegram]! Рада снова видеть тебя 👋"
- Видна только для клиентов с хотя бы одной записью
- Высота: 52px, горизонтальные паддинги 16px

**Блок 3 — "Записаться снова"** *(только при наличии истории)*
- Горизонтальная карточка на полную ширину
- Иконка слева (эмодзи или цвет услуги)
- Название последней услуги — 16px bold
- Подпись: "Последний визит: 12 мая" — 13px серый
- Кнопка "Снова" справа — pill-форма, акцентный фон, 13px, высота 32px
- Действие: переход сразу на экран выбора времени для этой услуги

**Блок 4 — Категории услуг**
- Заголовок "Что хочешь сделать?" — 17px bold, отступ 16px
- Горизонтальный scroll (без скроллбара) из chip-кнопок:
  - 💅 Маникюр
  - 🦶 Педикюр
  - 👁 Брови
  - 💆 Уход за кожей
  - *(добавляются мастером)*
- Каждый chip: высота 36px, горизонтальный паддинг 16px, скруглённый (border-radius 18px)
- Активный chip: акцентный фон + белый текст

**Блок 5 — Популярные услуги**
- Заголовок "Популярные" — 17px bold
- Вертикальный список карточек услуг (см. компонент ServiceCard ниже)
- 3 карточки без пагинации, кнопка "Все услуги →" под списком

**Блок 6 — О мастере (collapsed)**
- Маленькая карточка: аватар + 1 строка текста + рейтинг
- Тап → переход на таб Мастер

#### Действия на экране
| Действие | Результат |
|---|---|
| Тап на кнопку "Снова" | Экран выбора времени для последней услуги |
| Тап на chip категории | Таб Услуги с активным фильтром |
| Тап на карточку услуги | Карточка услуги |
| Тап "Все услуги →" | Таб Услуги |
| Тап на блок "О мастере" | Таб Мастер |

### Экран 2: Услуги (каталог)

**Назначение:** просмотр и выбор услуги

#### Элементы

**Поиск**
- Input с иконкой лупы — sticky под навбаром
- Placeholder: "Найти услугу..."
- Высота: 44px, border-radius 12px, фон `--tg-theme-secondary-bg-color`
- Поиск instant (debounced 300ms), без кнопки "найти"

**Фильтры — горизонтальный scroll chips**
- "Все" (активен по умолчанию)
- Категории: "Маникюр", "Педикюр", "Брови", ...
- Chips высота 32px, sticky под строкой поиска
- Scroll без scrollbar

**Список услуг**
- Вертикальный scroll
- Каждая карточка — компонент ServiceCard:

```
┌─────────────────────────────────────┐
│ [ФОТО 80×80px]  Название услуги     │
│   rounded sq    14px bold           │
│                 ⏱ 60 мин  💰 1500₽  │
│                 ★ 4.9 (23 отзыва)   │
│                         [Записаться]│
└─────────────────────────────────────┘
```

- Фото: 80×80px, border-radius 12px, object-fit cover
- Название: 16px bold
- Длительность + цена: 13px, иконки эмодзи или SVG, серый текст
- Рейтинг: 13px, звёздочка + число
- Кнопка "Записаться": height 36px, border-radius 10px, акцентный фон
- Высота карточки: 96px + паддинги = ~112px

**Пустое состояние поиска**
- Иллюстрация (простая SVG, не фото)
- Текст: "Ничего не нашлось"
- Подпись: "Попробуй другой запрос"
- Кнопка "Сбросить фильтр"

#### Действия на экране
| Действие | Результат |
|---|---|
| Тап на карточку услуги | Карточка услуги (детальный экран) |
| Тап на кнопку "Записаться" | Карточка услуги (детальный экран) |
| Тап на chip категории | Фильтр списка по категории |
| Ввод в поиск | Фильтрация списка в реальном времени |

### Экран 3: Карточка услуги

**Назначение:** убедить записаться — показать результат, цену, социальное доказательство

#### Элементы сверху вниз

**Галерея работ**
- Горизонтальный scroll фото: высота 260px, полная ширина
- Каждое фото — полная ширина экрана, object-fit cover
- Dots-индикатор под галереей (position absolute, снизу фото)
- Минимум 3 фото, рекомендуется before/after как первое
- Тап на фото → полноэкранный просмотр (lightbox)

**Заголовок и цена**
- Название услуги — 22px bold
- Горизонтальная строка:
  - ⏱ "60 минут" — 15px серый
  - разделитель "·"
  - 💰 "1 500 ₽" — 15px, акцентный цвет (выделить цену)

**Следующий доступный слот** *(если есть)*
- Бейдж: зелёный фон, белый текст, border-radius 8px
- Текст: "Ближайший слот: завтра в 11:00"
- Высота: 32px, паддинг 12px horizontal

**Описание**
- Максимум 3 строки по умолчанию, кнопка "Читать далее" если больше
- 15px, line-height 1.5
- Цвет: `--tg-theme-text-color`

**Отзывы** (2–3 штуки, не вся страница)
- Заголовок "Отзывы" + общий рейтинг ★ 4.9 (23)
- Каждый отзыв:
  - Аватар клиента 32px круглый (или инициал если нет фото)
  - Имя + дата — 13px серый
  - Фото работы (если есть) — 64px квадрат, border-radius 8px
  - Текст отзыва — 14px, максимум 2 строки
- Кнопка "Все отзывы →" под блоком

**MainButton (Telegram)**
- Текст: "Выбрать время"
- Появляется при открытии экрана
- При нажатии → экран выбора даты

#### Действия на экране
| Действие | Результат |
|---|---|
| Тап на фото | Полноэкранный просмотр (lightbox) |
| Тап на бейдж слота | Сразу экран выбора времени |
| Тап "Читать далее" | Разворачивает описание |
| Тап "Все отзывы →" | Список всех отзывов |
| MainButton "Выбрать время" | Экран выбора даты |
| BackButton | Назад в каталог |

### Экран 4: Выбор даты

**Назначение:** быстро найти свободный слот

#### Элементы

**Шапка экрана**
- Название услуги — 15px серый (reminder)
- Цена — 15px (reminder)
- Прогресс-индикатор: "Шаг 1 из 2" или три точки (● ○ ○)

**Компонент "Месяц"**
- Заголовок: "Май 2026" + стрелки ← →
- Сетка дней недели: Пн Вт Ср Чт Пт Сб Вс — 13px серый
- Дни:
  - **Доступен** — обычный текст, тапабельный
  - **Выбран** — круг акцентного цвета, белый текст
  - **Занят полностью** — серый текст, не тапабельный
  - **Прошедший** — светло-серый, не тапабельный
  - **Сегодня** — обводка акцентным цветом
- С точкой под числом — есть хотя бы один слот
- Размер ячейки: min 44×44px

**Блок "Доступное время"** *(появляется после выбора дня)*
- Заголовок: "Суббота, 17 мая" — 17px bold
- Сетка временных слотов:
  ```
  [10:00] [11:00] [12:00]
  [14:00] [15:30] [17:00]
  ```
  - Каждый слот: ширина ~80px, высота 44px, border-radius 10px
  - Доступный: фон `--tg-theme-secondary-bg-color`, текст обычный
  - Выбранный: акцентный фон, белый текст
  - Занятый: серый фон, серый текст зачёркнутый, не тапабельный
- Haptic feedback при выборе слота: `impactOccurred('light')`

**MainButton**
- Появляется после выбора слота
- Текст: "Продолжить"
- При нажатии → экран сводки

#### Действия на экране
| Действие | Результат |
|---|---|
| Тап на стрелки ← → | Переключение месяца |
| Тап на доступный день | Раскрывает слоты этого дня |
| Тап на слот | Выбор слота, haptic feedback |
| MainButton "Продолжить" | Экран сводки бронирования |
| BackButton | Назад на карточку услуги |

## 5. Чего НЕ будет в первой версии

### Исключено из v1 (сделаем в v2+)

| Функция | Почему отложено |
|---|---|
| **Оплата через Telegram Payments** | Требует подключения провайдера, верификации, юридического оформления |
| **Витрина товаров** (косметика, средства) | Отдельная бизнес-логика, не блокирует MVP |
| **Несколько мастеров / салон** | MVP для одного мастера |
| **Система отзывов** (оставить отзыв) | Отзывы показываем из статичных данных |
| **Реферальная программа** | Кнопка "Поделиться" есть, но без баллов |
| **Программа лояльности** (штамп-карта) | v2 |
| **Аналитика для мастера** | Отдельное приложение/панель |
| **Маркетплейс / поиск мастеров** | Другой продукт |
| **Push-уведомления о скидках и акциях** | Напоминания о записях — да, промо — нет |
| **Видео в галерее** | Сложность загрузки, v2 |
| **Повторное бронирование с выбором нового мастера** | v2 |
| **Выбор мастера** из нескольких | MVP — один мастер |
| **Кастомизация темы для мастера** | Используем Telegram-тему |
| **Веб-версия вне Telegram** | Только TMA |
| **Чат с мастером** внутри приложения | Есть нативный Telegram-чат |
| **Онбординг-туториал** | Интерфейс должен быть интуитивным без туториала |

## 6. Дизайн-система

### Принципы

1. **Telegram-native.** Используем только цвета из `themeParams`. Никаких хардкоженных #HEX.
2. **Touch-first.** Минимальная область касания — 44×44px для любого интерактивного элемента.
3. **Визуал главнее текста.** Фото занимает не менее 40% площади любого экрана с услугами.
4. **Один акцент на экран.** Только один элемент с `--tg-theme-button-color` в один момент.

### Цвета (CSS-переменные Telegram)

```css
--tg-theme-bg-color            /* основной фон */
--tg-theme-secondary-bg-color  /* вторичный фон (карточки, input) */
--tg-theme-text-color          /* основной текст */
--tg-theme-hint-color          /* вторичный текст, подписи */
--tg-theme-link-color          /* ссылки */
--tg-theme-button-color        /* акцентный фон кнопок */
--tg-theme-button-text-color   /* текст на кнопках */
```

Дополнительные (не из Telegram, нейтральные):
```css
--color-success: #34C759   /* зелёный — успех, доступный слот */
--color-error:   #FF3B30   /* красный — отмена, занято */
--color-warning: #FF9500   /* оранжевый — скоро, предупреждения */
```

### Типографика

```css
/* Системный шрифт — не грузить сторонний */
font-family: -apple-system, BlinkMacSystemFont, 'Roboto', sans-serif;

/* Размеры */
--text-xl:   22px;  /* заголовки экранов */
--text-lg:   17px;  /* заголовки секций, акцентный текст */
--text-md:   15px;  /* основной текст */
--text-sm:   13px;  /* подписи, вторичный текст */
--text-xs:   11px;  /* метки, бейджи */

/* Веса */
--weight-bold:    700;
--weight-medium:  500;
--weight-regular: 400;
```

### Отступы

```css
--spacing-xs:  4px;
--spacing-sm:  8px;
--spacing-md:  16px;  /* основной горизонтальный паддинг */
--spacing-lg:  24px;
--spacing-xl:  32px;
```

### Компоненты

**Кнопка Primary**
- Высота: 50px
- border-radius: 12px
- font-size: 16px, font-weight: 600
- background: `--tg-theme-button-color`
- color: `--tg-theme-button-text-color`
- Полная ширина в контексте форм

**Кнопка Secondary (outline)**
- Высота: 50px
- border: 1.5px solid `--tg-theme-button-color`
- background: transparent
- color: `--tg-theme-button-color`

**Кнопка Small**
- Высота: 36px
- border-radius: 10px
- font-size: 14px, font-weight: 500

**Chip (фильтр)**
- Высота: 32–36px
- Горизонтальный паддинг: 14px
- border-radius: 18px (pill)
- Неактивный: `--tg-theme-secondary-bg-color`, текст `--tg-theme-text-color`
- Активный: `--tg-theme-button-color`, текст `--tg-theme-button-text-color`

**Карточка**
- border-radius: 16px
- background: `--tg-theme-secondary-bg-color`
- Без border, без тени (flat design в стиле Telegram)
- Паддинг внутри: 16px

**Input**
- Высота: 44px
- border-radius: 12px
- background: `--tg-theme-secondary-bg-color`
- border: none
- font-size: 15px

### Анимации (только лёгкие)
- Переходы между экранами: `transform: translateX` за 250ms ease
- Skeleton fade: `opacity` 0.5→1 пульсация, 1.5s infinite
- Success checkmark: CSS keyframe, 400ms
- Слот выбора: `scale(0.95)` tap effect, 100ms
- Haptic вместо анимации там, где возможно

### Обязательные вызовы Telegram SDK

```javascript
// При старте
Telegram.WebApp.expand()

// Навигация
Telegram.WebApp.BackButton.show()     // на суб-экранах

// MainButton
Telegram.WebApp.MainButton.setText('Выбрать время')
Telegram.WebApp.MainButton.show()
Telegram.WebApp.MainButton.showProgress(false)
Telegram.WebApp.MainButton.hideProgress()
Telegram.WebApp.MainButton.onClick(handler)

// Аутентификация
const user = Telegram.WebApp.initDataUnsafe.user
// Верификация initData на бэкенде через HMAC-SHA256

// Haptic
Telegram.WebApp.HapticFeedback.impactOccurred('light')     // тап на слот
Telegram.WebApp.HapticFeedback.impactOccurred('medium')    // выбор категории
Telegram.WebApp.HapticFeedback.notificationOccurred('success') // подтверждение
Telegram.WebApp.HapticFeedback.notificationOccurred('error')   // ошибка

// Высота
const height = Telegram.WebApp.viewportStableHeight // НЕ 100vh

// Тема
Telegram.WebApp.onEvent('themeChanged', applyTheme)
const { bg_color, text_color, button_color } = Telegram.WebApp.themeParams

// Диалоги
Telegram.WebApp.showConfirm('Отменить запись?', callback)

// Ссылки

// Шаринг

```

### Структура данных (минимальная схема)

```
Мастер (master)
├── id, name, bio, photo_url
├── specializations: string[]
├── experience_years: number
├── works_count: number
├── rating: number
└── contacts: { instagram?, telegram_username? }

Услуга (service)
├── id, master_id
├── title, description
├── category: string
├── price: number
├── duration_minutes: number
├── photos: string[] (URLs)
└── rating, reviews_count

Слот (time_slot)
├── id, service_id, master_id
├── datetime: timestamp
└── is_available: boolean

Запись (booking)
├── id, client_telegram_id, service_id
├── slot_id, datetime
├── status: 'confirmed' | 'cancelled' | 'completed'
└── created_at

Отзыв (review) — только для отображения в v1
├── id, booking_id, client_name
├── rating, text
└── photo_url?
```

- Первый contentful paint: < 1 секунды
